# perplexity-mcp

A local stdio MCP server that exposes the Perplexity API (Agent API, Search API, Decisions, embeddings) to Claude. TypeScript, ESM, MCP TypeScript SDK v2 (`@modelcontextprotocol/server`), official `@perplexity-ai/perplexity_ai` SDK.

## Commands
- `npm test`: builds, then runs `node --test test/*.test.mjs`. Tests import from `build/`, so a stale build means stale results. Run one file with `npm run build && node --test test/agent.test.mjs`
- Live API check: `PERPLEXITY_API_KEY=... node scripts/validate-params.mjs`. Run it after adding or renaming any request param (see Gotchas). It costs a few cents
- `npm run pack:mcpb` builds the Claude Desktop bundle into `dist/mcpb/` (gitignored)

## Gotchas
- Neither TypeScript nor the Perplexity SDK's generated types catch request-param mistakes. SDK calls go through `as Function`/`as any` casts, and the SDK types have been wrong in both directions (e.g. they list `search_mode` on `/search`, which the API rejects). A live `validate-params.mjs` run is the only reliable check. The generated types are in `node_modules/@perplexity-ai/perplexity_ai/dist/generated/api.d.ts`
- Endpoints disagree on unknown body keys. The Search API silently ignores unknown and camelCase keys, so a typo looks like it works (it wants snake_case). The Agent and Decisions APIs reject unknown fields with a 400
- stdout carries only MCP JSON-RPC. Log through `src/utils/logger.ts` (stderr); `console.log` corrupts the protocol stream
- `search` and `async_research_submit` run on the Agent API by default because Sonar Chat Completions reached end of support on 2026-09-27. `PERPLEXITY_SEARCH_BACKEND=sonar` is the rollback path only
- A tool with an `outputSchema` must return `structuredContent` on every success path (use `structuredResult()`), or clients reject the result. Claude Code may hand the model only the JSON, so put everything the model needs in it
- Server `instructions` (`src/server/instructions.ts`) describe tool behaviour and are capped at 4,096 chars by a test. Update them when tools, routing keywords or filters change
- Version lives only in `package.json`. `manifest.json`'s `version` and `tools` are generated by `npm run mcpb:manifest`, so don't hand-edit them
- The API catalog drifts (models, effort names, limits). Prefer facts verified live and dated in `.claude/rules/` or `.claude/research/` over recalled knowledge, and re-verify before relying on an old one

## Environment
- `PERPLEXITY_API_KEY` is required; startup exits with an error on stderr without it
- `PERPLEXITY_MODEL` (default `sonar-pro`) must be one of `sonar`, `sonar-pro`, `sonar-reasoning-pro`, `sonar-deep-research`, or startup fails. `sonar-reasoning` was removed in Dec 2025
- `PERPLEXITY_SEARCH_BACKEND` (`agent` default, `sonar` rollback) and `PERPLEXITY_MCP_DEBUG` (any non-empty value logs debug output to stderr) are optional
- Requests time out after 5 minutes; anything longer belongs in `async_research_submit` + `async_research_status`

## Conventions
- Handlers take `(request, ctx)` and pass `ctx` as the last argument to every `PerplexityApiService` method, so a client cancel aborts the HTTP call
- Handlers throw `ErrorHandler.validationError()` for bad input and let API errors throw. The dispatcher turns them into `isError` results. Only an unknown tool name is a protocol error
- Every tool needs a `TOOL_METADATA` entry (title + all four annotation hints) in `src/schemas/toolSchemas.ts`; the rationale is commented there. The steps for adding a tool's tests are in `.claude/rules/testing.md`

## Deprecated, remove next release
`async_research` (→ `async_research_submit`/`_status`/`_list`) and `model_info` (→ `get_model_info`/`set_model`). To delete one: its `TOOL_DEFINITIONS` + `TOOL_METADATA` entries, its `toolHandlers` line, the alias `handle()` method (and `isValidAsyncResearchArgs`/`isValidModelArgs` once unused), and its rows in `test/server.test.mjs` and `test/structure.test.mjs`. The stateful filter tools (`domain_filter`, `recency_filter`, `clear_filters`, `list_filters`) are deprecated with no removal date.
